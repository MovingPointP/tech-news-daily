React 19 Server Components は、クライアント側の JavaScript ペイロードを削減し、初期レンダリングパフォーマンスを向上させます。
静的シェルと動的パーツのストリーミングを組み合わせたアーキテクチャが一般的なパターンとして採用されています。
Server Components ではフック実行されず、データ取得と重い処理はサーバーで実行することが推奨されています。
パフォーマンスメトリクスとして、LCP は 2.5 秒未満、INP は 200 ミリ秒以下を目標としています。
データ集約的なシナリオでは Server Components による効果が特に顕著で、Next.js 15 での Partial Prerendering が実装の標準になってきています。

### [Tracking down the 16-year-old WAL-reset SQLite bug](https://news.ycombinator.com/item?id=49272832)
SQLiteのWrite-Ahead Logging（WAL）サブシステムに16年間潜んでいた致命的なバグが発見されました。
Tailscaleが2025年に経験した6ヶ月間のアップタイム問題がこのバグの原因だったことが判明しました。
バグは複数のデータベース接続がWALモードで開かれている場合に発生する競争状態です。
チェックポイントと書き込みトランザクション間の同時アクセスが問題を引き起こしていました。
SQLiteは3.51.3でこのバグを修正し、Tailscaleと協力して問題を完全に解決しました。

### [The Google Merchant API migration has a silent mispricing trap (Content API shuts down Aug 18, 2026)](https://dev.to/flarecanary/the-google-merchant-api-migration-has-a-silent-mispricing-trap-content-api-shuts-down-aug-18-2026-2gkn)
Google Content API for ShoppingからMerchant APIへの単純な置き換えには隠れた落とし穴があります。
基本URLの置き換えだけでは、APIが200レスポンスを返しながら間違ったデータを本番カタログに書き込む危険があります。
金額フィールド「amountMicros」がint64型であるため、文字列の「15.99」が15に切り詰められてしまう問題が発生します。
結果として全商品が$0.000015の価格で登録され、Google Shoppingで表示されることになります。
2026年8月18日のContent API廃止前に、この問題に気付かないと大きな売上損失に繋がる可能性があります。

### [Auto mode is now Claude Code's default: what the classifier approves, and how to switch back](https://dev.to/rulestack/auto-mode-is-now-claude-codes-default-what-the-classifier-approves-and-how-to-switch-back-4j2j)
2026年8月14日から、Pro、Max、Teamプランの新しいClaude Codeセッションではauto modeがデフォルトになりました。
auto modeは「権限をスキップ」するのではなく、各アクション前に独立した分類器モデルで安全性を検証します。
分類器は、ユーザーのリクエストを超える権限昇格や、認識されていないインフラへの変更を検出ブロックします。
プロンプトインジェクションなど敵対的コンテンツが駆動する可能性のあるアクションも検出し制限します。
ユーザーはいつでも権限モードを切り替えることが可能で、既に設定したデフォルトを優先する設定も保持されます。

### [The End of Undetectable AI Text? Claude's New Watermark Explained](https://dev.to/sylwia-lask/the-end-of-undetectable-ai-text-claudes-new-watermark-explained-45g2)
Anthropicが2026年8月2日より新しいClaudeモデルにテキスト透かし機能を導入しました。
透かしはテキスト内に埋め込まれた見えない痕跡で、Claudeの単語選択に微妙なバイアスを加えることで実装されています。
EU AI法第50(2)条の透明性コード・オブ・プラクティスへの準拠が変更の背景にあります。
重い編集や言い換え、翻訳、または短いテキストセグメントではこの透かしが検出不可能になる可能性があります。
透かしの有無だけでそのテキストがAIで生成されたか否かの判断はできない性質があります。
